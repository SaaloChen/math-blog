# Saalo Math Site

A starter Quarto website for an English academic homepage and mathematical blog.

## Local preview

Install Quarto, then run:

```bash
quarto preview
```

## Render

```bash
quarto render
```

## Publish idea

Create a GitHub repository, push these files, then publish with GitHub Pages.

Replace these placeholders before publishing:

- `https://example.com` in `_quarto.yml`
- `https://github.com/your-github-username` in `_quarto.yml`
- CV text in `cv.qmd`
Initial setup.
